= `qsh_bug`

----
qsh_bug [<text>...]
----

Prints a bug message to `stderr` and terminates the script.

If at least one `<text>` argument is given, the message will be the
space-separated concatenation of the `<text>` arguments.
Otherwise, the message will default to `"Unknown bug"`.

The message will be prefixed with `"$0: Bug: "` and suffixed with `"."`.

If `qsh_exit_status` is set, it will be used as the exit status.
Otherwise, the exit status will default to 3.
